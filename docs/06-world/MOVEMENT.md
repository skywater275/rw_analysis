## 2. MovementController — 每帧移动更新 (1761行)

**文件**: `com/corrodinggames/rts/game/MovementController.java`

每个移动单位有一个 MovementController 实例。

### 2.1 核心字段

| 字段 | 类型 | 含义 |
|------|------|------|
| `eo, ep` | float | 世界坐标 (X, Y) |
| `az` | float | 当前朝向角度 (度, 0=右, 90=上) |
| `t` | float | 当前速度 (单位/秒) |
| `u, v, w` | float | 速度分量 (X, Y, Z) |
| `h` | float | 移动前延迟 |
| `i` | float | 暂停计时器 |
| `j` / `l` | am | 追踪的目标实体 |
| `n, o` | float | 目标位置 (X, Y) |
| `m` | boolean | 是否有固定位置目标 |
| `K, L` | float | 轨道偏移 (环绕目标运动) |

### 2.2 主更新方法: `a(float dt)` (line 588)

```
1. 延迟/暂停处理 (lines 603-627)
   ├── i > 0 → 倒计时, do nothing
   └── h > 0 → 倒计时

2. 目标重选 (lines 630-647)
   └── 如果目标死亡或定期刷新, 搜索附近实体

3. 环绕/编队偏移 (lines 648-688)
   ├── g.R / g.S != 0 时:
   └── K, L = sin/cos(time) × 偏移量 → 圆形运动模式

4. 距离/方向计算 (lines 692-744)
   ├── 目标位置 = 实体位置 + 环绕偏移
   ├── f11 = 直线距离
   └── f9 = 目标高度

5. 速度调整 (lines 745-755)
   ├── 远距离: g.O 速度倍率
   └── 近距离 (<225²): g.P 速度倍率 → 平滑减速

6. 位置积分 (lines 785-846)
   ├── eo += u × dt,  ep += v × dt,  eq += w × dt
   ├── 重力: 高度 > 0 且 g.G 重力 → 高度下降
   └── 升降控制:
       ├── aH 模式: 固定升力速度 + 上下界 (aI, aJ)
       └── 正常模式: 高度调整与距离成正比

7. 速度渐变 (lines 848-856)
   ├── r = 最大速度, s = 加速度
   └── g.am = 可选侧向漂移
```

### 2.3 到达检测 (lines 904-1060)

```
到达条件:
├── 距离 < 6 单位 (或大型实体的 80% 半径)
├── 高度差 < 3 单位 + 速度
└── OR:
    ├── as 模式: 与非友军单位重叠
    └── at 模式: 处于不可通行地形

到达后:
├── 停止移动 (bn=true)
├── 触发到达特效 (粒子/音效/地面贴花)
├── 施加接触伤害 (E 模式: 非环绕 = U 伤害, 环绕 = 推动目标)
└── 生成携带单位 (g.ba > 0 且为 j 类型)
```

## 3. 路径规划 — 双向A*引擎

### 3.1 架构

```
前台 (游戏线程):
├── l.java (k/)   ← 路径引擎协调
└── k.java (k/)   ← 路径请求

后台线程:
├── o.java (k/)   ← 路径求解器 (Runnable, "PathSolver-N" 线程)
├── i.java (k/)   ← 代价地图 (每种移动类型一个)
├── n.java (k/)   ← 导航数据 (每格)
├── p.java (k/)   ← 路径节点 (网格坐标)
└── m.java (k/)   ← 最小堆优先队列
```

### 3.2 代价地图 (i.java)

对于每种移动类型，创建一个代价地图:

| 数组 | 类型 | 含义 |
|------|------|------|
| `d` | byte[] | **地形代价** (-1 = 不可通行) |
| `e` | byte[] | **建筑代价** (-1 = 被建筑阻挡) |
| `f` | byte[] | **单位代价** (-1 = 被单位阻挡) |
| `g` | short[] | **孤立组ID** (用于连通性检查) |
| `j` | byte[] | **裕度代价** (0-4, 4=开阔, 0=被阻挡) |

**裕度代价 (clearance) 计算** (lines 116-145):
```
对每个被阻挡格 → 向外传播距离 (最多3格)
结果: 每个格子记录离最近障碍物的距离
A* 使用此值惩罚通过狭小间隙的路径
```

### 3.3 A* 求解器 (o.java, 方法 e(), lines 274-660)

**关键特性**:

1. **双向搜索**: 从起点 (`this.o`) 和终点 (`this.p`) 同时搜索，每 400 次迭代切换方向 (lines 441-461)

2. **8方向移动** (lines 552-579):
```
0: 东 (+x)
1: 东北 (+x,+y)
2: 北 (+y)
3: 西北 (-x,+y)
4: 西 (-x)
5: 西南 (-x,-y)
6: 南 (-y)
7: 东南 (+x,-y)
```

3. **代价函数** (lines 580-607):
```
基础代价 = 10 (直走) 或 14 (对角线)  ← 标准八分距离
+ 转向代价: 90°转弯 = 21, 其他 = 4-25  ← 鼓励直走
+ 裕度代价: (4 - j[x,y]) × 权重         ← 惩罚贴墙
+ 禁区代价: +100 (如果在限制区)
```

4. **不可达目标回退** (lines 323-427):
```
如果目的地在不同的孤立组 (不同岛屿):
├── 从目的地向外扩展搜索 (最多25格 → 全地图)
└── 找到最近的可达格作为新目的地
```

5. **无完整路径回退** (lines 615-637):
```
如果没找到完整路径:
└── 遍历所有已访问节点, 返回离目的地最近的那个
```

### 3.4 路径请求流程

```
1. 单位需要移动
2. 创建 k 对象 (起点/终点网格坐标 + 移动类型)
3. 路径延迟 k.t 设置:
   ├── 极短路: 12s
   └── 长路: 360s
4. 调度:
   ├── 短路 → 同步处理
   └── 长路 → 后台线程 (o.a(k) + o.b() 通知)
5. 结果 → LinkedList<p> (网格坐标序列)
6. 单位按路径点依次移动
```

## 5. 移动系统完整管线

```
用户/AI 发出移动指令
│
▼
Command.k() — 指令执行
├── 设置 waypoint 到单位
└── 单位.ar() 存储目标
│
▼
路径请求 (如果需要路径规划)
├── 创建 k 对象 (起点/终点/移动类型)
├── 选择代价地图 (按移动类型)
└── 后台 A* 求解器
    ├── 双向搜索 (起点↔终点)
    ├── 8方向移动 + 转向代价
    ├── 裕度检查 (避开狭窄通道)
    └── 返回路径点序列
│
▼
MovementController.a(dt) — 每帧更新
├── 朝向当前路径点转向
├── 加速/减速 (平滑运动)
├── 高度调整 (升力/重力)
├── 碰撞检测 (空间网格查询)
└── 到达检测 → 切换到下个路径点
│
▼
到达最终目的地
├── 触发特效/音效
├── 执行到达回调
└── 单位进入空闲状态
```

## 7. 对 RWAgent 的影响

1. **移动指令构造**: 使用 `Command.a(float x, float y)` 设置移动目标，`e.o`/`e.n` 是目标位置
2. **建造指令构造**: 使用 `Command.a(float x, float y, as type, int stages)`，需要正确的移动类型
3. **路径阻塞**: 如果目标在不同孤立组 (island)，A* 回退到最近可达点
4. **裕度影响**: 在密集基地中，裕度代价可能阻止建造者到达建造位置
5. **到达检测**: 建造者需在建造位置 6 单位内才能开始建造

## 8. A*寻路引擎详解 (2026-06-23 新增)

> 关键文件: `gameFramework/k/`(17个类)
> 详见: [ASTAR-PATHFINDING.md](ASTAR-PATHFINDING.md)

### 8.1 架构

```
PathFinder(l) — 主管理器 (静态)
├── PathSolver(i)[] — 每区块求解器 (byte[]代价图)
├── PathSolverRunner(o) — 后台工作线程 (976行, LinkedList任务队列)
│   ├── AStarSearch(d) — PriorityQueue A* (975节点数组)
│   │   ├── AStarNode(n) — 搜索节点 (Comparable, Manhattan+对角线启发式)
│   │   ├── NodePool(m) — 预分配1000节点池 (GC-free)
│   │   └── NodeQueue(e) — 两级优先级队列 (低/高代价桶)
│   ├── PathCostCalc(f) — 移动代价计算器
│   └── TerrainCost(g) — 地形代价图 (byte[]数组)
└── PathNode(p) — 最终路径位置 (short x/y)
```

### 8.2 核心算法

**AStarSearch(d)**: PriorityQueue + 975节点固定数组 + 双向搜索
```java
// 启发式: Manhattan距离×11 + 对角线修正×(-7)
cost = g + (|dx| + |dy|) * 11 + min(dx,dy) * (-7)
```

**NodePool(m)**: 预分配策略
```java
// 初始化时预分配1000个AStarNode
// 搜索中从池获取，用完后归还
// 池空时才new — 大多数搜索零GC
```

**NodeQueue(e)**: 两级分桶
```java
// 低代价桶 (容量100) — 当前代价层
// 高代价桶 (容量900) — 高于阈值
// 低代价桶空后切换并更新阈值
```

### 8.3 代价计算

```
总代价 = b[x][y] + c[x][y] + d[x][y] * 10
// b = 基本地形代价
// c = 碰撞/障碍代价
// d = 额外惩罚 (如密集建筑区)
```
